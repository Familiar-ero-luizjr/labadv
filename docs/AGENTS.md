# AGENTS.md — Docs

## Missão

Manter **documentação técnica viva** do Advogado Já.

Docs pode apoiar auditorias, implementação, operação e manutenção, mas não possui autoridade para decidir produto.

## Autoridade

Em conflito funcional:

decisão atual → jornada vigente → artefato especialista → docs.

Documentação desatualizada deve ser corrigida; não usar sua existência para contrariar a fonte canônica.

## Conteúdo adequado

- arquitetura técnica;
- contratos documentados;
- procedimentos;
- homologação;
- infraestrutura autorizada;
- decisões técnicas já aprovadas;
- guias de operação/manutenção.

## Conteúdo inadequado

Não registrar como verdade uma hipótese funcional ainda aberta.

Propostas devem ser marcadas como proposta e encaminhadas para Orquestração/jornada quando impactarem produto.

## Atualização

Quando uma revisão de jornada alterar comportamento técnico relevante, atualizar docs afetados no mesmo ciclo de sincronização.

## Segurança

Não inserir segredos, tokens, credenciais, dados pessoais reais ou endpoints privados sensíveis.
