# AGENTS.md — Legado

## Missão

Preservar versões e implementações históricas para comparação e recuperação de contexto.

## Regra principal

Legado **não é fonte de verdade atual**.

Nunca restaurar tela, fluxo, banco, Function, regra, rota ou arquitetura apenas porque já existiu.

## Uso permitido

- comparar comportamento;
- localizar decisões antigas;
- recuperar assets/estruturas quando a versão atual explicitamente autorizar;
- identificar regressões ou funcionalidades perdidas;
- apoiar auditorias.

## Uso proibido

- resolver lacuna funcional por inferência automática;
- sobrescrever jornada atual;
- copiar código sem verificar compatibilidade;
- tratar resposta/implementação histórica como aprovação vigente.

## Contexto

Ler legado somente quando a fase ativa exigir comparação específica. Evitar leitura ampla por padrão.
